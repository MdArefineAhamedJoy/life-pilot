# life-pilot

Life Pilot is a personal local-first dashboard for budget tracking, daily routine planning, timers, notes, reports, and future AI-assisted receipt parsing.

## Features

- Daily and monthly expense tracking
- Budget categories for bajar, personal, baby, family, and other costs
- Receipt/slip text-to-table parsing
- Routine task planning and status tracking
- Timer, stopwatch, and focus session history
- Notes and personal life database
- Reports and JSON backup/import
- Responsive sidebar and mobile navigation

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
